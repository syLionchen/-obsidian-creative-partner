# Contributing / 贡献指南

## English

Issues and pull requests are welcome.

- **Bug reports / feature requests**: open a GitHub Issue. Include your Obsidian version, the AI provider/protocol you're using, and steps to reproduce if it's a bug.
- **Pull requests**: fork the repo, create a branch, and open a PR against `main`. See the "Development" section in [README.md](README.md) for the build setup (`npm install`, `npm run dev` / `npm run build`).
- Keep PRs focused — one change per PR is easier to review than a bundle of unrelated fixes.

## 中文

欢迎提 Issue 和 Pull Request。

- **报 Bug / 提需求**：开一个 GitHub Issue。如果是 Bug，请带上你的 Obsidian 版本、使用的 AI Provider/协议，以及复现步骤。
- **提交代码**：fork 本仓库，开一个分支，对 `main` 发 PR。构建方式见 [README.md](README.md) 里的"开发"章节（`npm install`、`npm run dev` / `npm run build`）。
- PR 尽量聚焦在一件事上——一个 PR 只改一件事，比堆一堆不相关的改动更容易被审核通过。
